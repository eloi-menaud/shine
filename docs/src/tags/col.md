# `<col>` (column)

Container tag used to display multiple children vertically.

<br><br>

**Containes:** a list of tags

**Attributes:**
|name|type|description|default|
|:-|:-|:-|-|
|`spacing`| [Pixel](attribute_types.md#pixel) | Space between elements inside the container|`0`|
|`width`| [Length](attribute_types.md#length) | Width of the container|`shrink`|
|`height`| [Length](attribute_types.md#length) | Height of the container|`shrink`|
|`padding`| [Padding](attribute_types.md#padding) | Inner spacing around the container's content|`0`|
|`bg_color`| [Color](attribute_types.md#color) | Background color|`#00000000`|
|`border_width`| [Pixel](attribute_types.md#pixel) | Thickness of the container's borders|`0`|
|`border_color`| [Color](attribute_types.md#color) | Color of the borders|`#00000000`|
|`border_radius`| [Radius](attribute_types.md#radius) | Curvature radius of the container's corners|`0`|
