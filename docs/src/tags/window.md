# <window\> (window)

The root tag of you application, used to specify the application metadata.

A SXML schema **must** have a `<window>` tag as root tag.

This tag can **only** be used as root tag. So it's must be unique and can't be pass as child of other tags

<br><br>

**Containes:** 1 tag

#### Attributes:
|name|type|description| default |
|:-|:-|:-|:-|
|`title`| String | the name of the window | `Shine app` |
