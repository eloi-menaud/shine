# `<row>` (row)

Containers tag used to display multiple children horizontally.

<br><br>

**Contains:** a list of tags 

**Attributes:**

|name|type|description|
|:-|:-|:-|
|`spacing`| [Pixel](attribute_types.md#pixel) | Space between elements inside the container|
|`width`| [Length](attribute_types.md#length) | Width of the container|
|`height`| [Length](attribute_types.md#length) | Height of the container|
|`padding`| [Padding](attribute_types.md#padding) | Inner spacing around the container's content|
|`bg_color`| [Color](attribute_types.md#color) | Background color|
|`border_width`| [Pixel](attribute_types.md#pixel) | Thickness of the container's borders|
|`border_color`| [Color](attribute_types.md#color) | Color of the borders|
|`border_radius`| [Radius](attribute_types.md#radius) | Curvature radius of the container's corners|
